# Forma working agreements

- Build for small architecture, design and creative teams that need durable shared context.
- Preserve the editorial visual language: soft lavender, paper surfaces, serif titles and generous reading space. Make it distinct from other portfolio products.
- Support mobile, tablet, desktop and light/dark themes. Use Radix primitives for interaction and React Icons for marks.
- Use strict TypeScript, Next App Router and Prisma/SQLite. Keep credentials and private documents out of Git.
- Add or update meaningful tests for each behavior and edge case.
- Daily work reviews prior changes, updates tests, implements the scheduled slice, debugs, updates documentation/backlog and plans tomorrow.
- Never commit .npmrc, .env, credentials or generated output. Never force push. Report blocked checks with their exact command and cause.
- Follow DAILY_WORKFLOW.md and BACKLOG.md. Completion includes accessibility, responsive states, tests and docs.

## Delivery from Day 02

- Read and follow [DELIVERY-POLICY.md](DELIVERY-POLICY.md). Finish Forma Team Library and its own PR panel review, merge and sync before the next portfolio repository, or record an exact external blocker. No concurrent project or subagent work.
- Choose commit counts, boundaries, content and wording from this product's real changes; do not copy a fixed history pattern from other projects.
- Review the latest pushed head and checks in GitHub and merge through this repository's PR panel. Respect required independent approvals; self-review does not replace them.

## Community contribution goals — effective Day 02

- Read [CONTRIBUTING.md](CONTRIBUTING.md) at startup. Integrate its Forma Team Library examples and real collaboration opportunities into existing daily/weekly/documentation work. Preserve sequential delivery, product-specific commits and every PR gate.
- Recognition is account-wide and externally awarded. No activity quotas, fake coauthors, manufactured issues, star exchanges or review shortcuts; record actual evidence and uncertainty.
